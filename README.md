# Sammy

Persona-locked personal companion desk (Cut 1 spine).

## Requirements

- Rust stable + MSVC
- Node 20+
- KoboldCpp on `http://127.0.0.1:5001` for local brain testing
- Optional Venice API key (OS keychain)

## Run

```bash
npm install
npm run tauri dev
```
